# 第二组：纯直线粒子，五种方形边界

**研究目标**：先看现象，比较同一局部朝向对齐规则下，真实墙面与周期边界如何改变从随机初态出发的团簇形成、边界滞留、有序运动及长期状态。**所有输出保持白色背景。**

## 1. 实验分组

| 代号 | CLI | 具体模型 | 观察重点 |
|---|---|---|---|
| B1 | `mirror` | 方壁镜面反射，速度与推进朝向的对应法向分量反号 | 反弹后团簇重排、角点附近结构 |
| B2 | `sliding` | 方壁切向滑移：阻止向外法向位移，朝向角不被壁面强制旋转 | 贴壁滞留、角点堆积、沿壁迁移 |
| B3 | `mixed` | 每次**新碰壁**以概率 `p_spec=0.5` 镜面反射，否则切向滑移（概率逐壁可在代码扩展） | 中间行为、不同随机碰壁响应 |
| B4 | `soft` | 名义方壁内侧宽度 `2` 的谐势力层，强度 `4`，法向回推，非硬约束 | 穿透名义边界、壁面势引起的近壁速度变化 |
| B5 | `periodic` | 水平/竖直周期平移，最小镜像邻居搜索，正方形边框不是墙 | 无物理壁面的团簇与全局极化对照 |

未加入粒子间机械排斥。粒子在本阶段是可重叠点粒子，参数 `diameter` 虽在动力学通用数据结构中保留，但在 `repulsion_k=0` 时**不产生有限体积排斥**。

## 2. 统一参数

- 方形基本区域：`x,y ∈ [-25,25]`，`L=50`，面积 `2500`。与第一组圆形半径 `R=50/sqrt(pi)` 面积相同。
- `N=5000`，平均数密度 `rho=2`，`v0=1`，`r_align=1`，`dt<=0.02`，`seed=20261022`，`Omega_i=0`。
- 邻域内采用 `K / (1+邻居数量)` 的正弦差对齐项；含自身只在分母，分子自身贡献为零。
- 第一轮 `K=0,1.5`（10种边界-参数组合），第二轮 `K=0.5,3`（再10种）；总计20组，全部目标 `t=300`。
- 相同种子保证五种**方形**边界在 `t=0` 使用相同位置和朝向。与此前的圆形组由于取样几何不同，不应认为所有粒子初始位置逐个相同。
- 所有周期性距离、角度对齐采用周期最小镜像；轨迹图会在跨边界瞬间断线，避免假冒跨越盒子的直线。

## 5. 如何看现象

先看 `t=0` → 早期团簇 → 撞壁/跨边界 → 长期重排。关注：

- 从随机状态形成局部有序团簇的时间和结构；不同 `K` 的差异。
- 角点滞留、沿壁迁移与镜面反射后的团簇重排（仅实壁）。
- 软壁在名义边界内外的分布与粒子速度变化；不得把越过名义框线简单判断为数值错误。
- 周期性边界中跨左右/上下相连的团簇，不要误认为分裂或墙面富集。
- 体系全局极化 `P` 与邻居对齐 `Q`；这两者是不同量。
- 真实边界可测贴壁率与边界相关统计；周期性边界**没有**物理墙面，边界富集、贴壁率、墙面环流不定义。方壁切向、角点运动也不应简单等同圆壁整体环流。

`status=unconfirmed` 指到指定时刻结束的固定时间实验**尚未证明达到稳态**，不意味着数值积分失败。

## 6. 绘图规则

纯白背景，粒子统一蓝色，边界深灰细线，高清大图和单组 MP4 独立保存；不把全部箭头/轨迹压在同一画面。周期边框用**虚线**表示基本胞，软势起效位置在内部加**点线**，实墙用**实线**。不同边界空间尺度相同，t、N、K 都明示。

## 7. 本包实际试跑情况

**已经完成 `N=5000,K=0` 与 `K=1.5`、五种边界的早期实跑预览**（共10组；共同对比帧为 `t=8`；镜面边界两组及滑移 `K=0` 已计算到 `t=30`），用于检验程序和绘图，不是 `t=300` 的正式长时间结果。代码已通过9项回归测试（包括保存续算）；正式20组 `t=300` 需要在用户电脑继续执行。

**计算性能提醒：**在纯点粒子且可重合的模型中，滑移/混合边界可能使大量粒子集中到角点或壁面，局部对齐的精确近邻对数急剧增加，因此 `K=1.5`、尤其 `K=3` 的正式 `t=300` 仿真可能很慢。当前实现没有抽样或截断相互作用以加速；短时预览不能替代长时演化。若电脑出现持续高负载，先跑 `K=0` 组，再依次单独续算其他组，切勿把非常缓慢的运算当作已经达到稳态。
